# Wuthering Waves 3.5 — русификатор (PC + Android) от qwikki

Бесплатный русский текст для **Wuthering Waves 3.5** на ПК и Android. от qwikki

Новости и сборки: [Telegram](https://t.me/WuwaNewss)

Язык в настройках игры оставляйте **English**. Русификатор подменяет английские строки, голос не трогает.

**Стабильность:** на ПК и Android вылетов и проблем с запуском не наблюдается. Это только текст и шрифт, клиент игры не патчится.

## ПК (Windows)

Нужен **вьетнамский лоадер** (viet-hoa): `winmm.dll` + `wuwaVietHoa.dll` в папке  
`Wuthering Waves Game\Client\Binaries\Win64\`  
Без него игра не подхватит паки. Лоадер в этот репозиторий не входит — ставьте тот, которым уже пользуетесь. 
Найти его можно у нас в тг в закрепе!

### Установка

1. Полностью закройте игру.
2. Создайте папку (если её нет):  
   `Wuthering Waves Game\Client\Content\Paks\~mods\`
3. Скопируйте туда оба файла:
   - `pc/TiengViet_99_P.pak` — **текст**
   - `pc/TiengViet_98_P.pak` — **шрифт** (чтобы буква «Я» не разъезжалась)
4. В игре язык текста = **English**.
5. Запуск как обычно (официальный лаунчер). В консоли лоадера должны появиться `TiengViet_99` и `TiengViet_98`.

### Если не перевелось

- Игра была открыта — закройте и положите файлы снова.
- Нет viet-hoa dll в `Win64`.
- После патча игры файлы могли стереться — положите ещё раз.

## Android (Samsung и другие)

Root не нужен. Игра должна быть установлена из магазина и **хотя бы раз запущена**.

### Куда класть

```
Android/data/com.kurogame.wutheringwaves.global/files/UE4Game/Client/Client/Saved/Paks/
```

Файлы:

- `android/pakchunk0-Android_ASTC_10000_P.pak` — текст
- `android/pakchunk0-Android_ASTC_10001_P.pak` — шрифт

### Как закинуть

Обычный проводник Samsung папку `Android/data` не открывает.

**Вариант A — с компьютера (удобнее)**  
Включите «Для разработчиков» → отладка по USB → кабель → скопируйте два файла в путь выше через `adb` или файловый менеджер с доступом.

**Вариант B — на телефоне**  
Shizuku + ZArchiver / MT Manager / X-plore. Скопируйте оба `.pak` в `Saved/Paks`.

Язык в игре = **English**. После копирования полностью закройте игру и откройте снова.
